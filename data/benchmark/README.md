# Local benchmark datasets

## L3Cube-MeSent

Files are from the official [L3Cube-Pune MarathiNLP MeSent directory](https://github.com/l3cube-pune/MarathiNLP/tree/main/MeEval/L3Cube-MeSent):

- `me_sent/codemix-sent-train.csv`
- `me_sent/codemix-sent-val.csv`
- `me_sent/codemix-sent-test.csv`

Use `tweet` as the text column and `sentiment` as the label column. The dataset repository lists the data under CC BY-NC-SA 4.0; check the upstream license and attribution requirements before redistribution or commercial use.

Use the validation split for iteration and reserve the official test split for the final reported result.
